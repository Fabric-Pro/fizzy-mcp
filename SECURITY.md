# Security Policy

If you discover a security vulnerability in this project, please report it
privately using GitHub's private vulnerability reporting: go to the
[Security tab](https://github.com/Fabric-Pro/fizzy-mcp/security/advisories/new)
and click "Report a vulnerability".

Please do **not** report security issues via public GitHub issues or pull
requests.

Maintainers will respond as soon as possible.

## Supported Versions

Only the latest released version of this project is supported with security
updates.
